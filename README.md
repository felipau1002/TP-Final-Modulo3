# TP-Final-Modulo3


Objetivos:
- Crear una página web que consuma la API "https://restcountries.com/v3.1/region/america", traiga y guarde en la base de datos solo los paises que hablen español, muestre solo el nombre, capital, paises limítrofes, area, población y zonas horarias de estos paises y permita la creación de nuevos paises con el mismo formato o la edición de los existentes.


Tecnologías utilizadas:
- Javascript
- Express 
- Motor de vistas EJS
- Mongoose
- HTML y CSS


Pasos de Ejecución:
- Levantar el servidor con "node server.mjs", acceder a "http://localhost:3000/api/inicio" y presionar el botón "Cargar paises desde la API".
